# Office 檔案中繼資料清理工具

一個基於 PowerShell + .NET Windows Forms 的免安裝工具，用於批次清除 Office 檔案（Word、Excel、PowerPoint）的個人資訊與中繼資料，並還原檔案的原始時間戳記。

## 功能特點

- 🎯 **批次處理**：一次處理多個檔案和資料夾
- 📝 **支援多種格式**：Word (.doc, .docx)、Excel (.xls, .xlsx)、PowerPoint (.ppt, .pptx)、PDF (.pdf)
- 🔄 **三種操作模式**：
  - **清理模式**：清除中繼資料
  - **讀取模式**：匯出中繼資料至 CSV
  - **替換模式**：設定自訂中繼資料值
- 🔒 **隱私保護**：清除作者、公司、經理等敏感資訊
- ⏰ **時間戳記還原**：保持檔案原始的建立和修改時間
- 📊 **詳細報告**：自動生成 CSV 格式的處理報告
- 🖥️ **圖形介面**：直觀的雙標籤設計，操作簡單
- 🚀 **免安裝**：單一 .ps1 檔案，雙擊 .bat 即可執行

## 快速開始

### 方式 1：使用批次檔 (推薦)

1. 下載 `OfficeClear.bat` 和 `OfficeClear_Tool.ps1` 到同一資料夾
2. 雙擊 `OfficeClear.bat` 啟動工具
3. 在介面中選擇目標資料夾和處理選項
4. 點擊「開始執行」按鈕

### 方式 2：直接執行 PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File ".\OfficeClear_Tool.ps1"
```

## 使用說明

### 設置標籤

#### 1. 選擇目標資料夾
- 手動輸入路徑，或
- 點擊「瀏覽...」按鈕選擇資料夾

#### 2. 選擇檔案類型
選擇要處理的檔案類型（可多選）：
- ☑ Word (.doc, .docx)
- ☑ Excel (.xls, .xlsx)
- ☑ PowerPoint (.ppt, .pptx)
- ☐ PDF (.pdf)

#### 3. 選擇操作模式
選擇要執行的操作：
- ⦿ **清理模式**：清除選定的中繼資料（預設）
- ◯ **讀取模式**：僅讀取並匯出中繼資料至 CSV，不修改檔案
- ◯ **替換模式**：將中繼資料替換為指定的值

#### 4. 選擇中繼資料項目
選擇要處理的項目（可多選）：
- ☑ 標題 (Title)
- ☑ 主旨 (Subject)
- ☑ 作者 (Author)
- ☑ 經理 (Manager)
- ☑ 公司 (Company)
- ☑ 類別 (Category)
- ☑ 關鍵字 (Keywords)
- ☑ 備註 (Comments)

**快速操作**：
- 「全選」按鈕：勾選所有項目
- 「取消全選」按鈕：取消所有項目

#### 5. 替換模式選項（僅在替換模式下顯示）
當選擇「替換模式」時，會顯示文字輸入框，可為每個中繼資料項目設定要替換的值。
- 只有勾選的項目才會被替換
- 留空表示清除該項目（與清理模式相同）
- 可為不同項目設定不同的值

#### 6. 處理選項
- ☑ 包含子資料夾：遞迴處理所有子資料夾中的檔案

### 進度標籤

執行期間會自動切換到進度標籤，顯示：
- **進度條**：視覺化處理進度
- **狀態標籤**：當前處理的檔案名稱和進度 (n/總數)
- **執行日誌**：實時顯示處理結果
  - `[✓]` 表示成功
  - `[✗]` 表示失敗
  - `[i]` 表示一般資訊

### 控制按鈕

- **開始執行** (綠色)：開始執行選定的操作
- **取消** (紅色)：中止正在執行的任務
- **打開報告** (藍色)：開啟生成的 CSV 報告

## 處理報告

每次執行完成後，會在程式所在目錄自動生成 CSV 報告。

### 報告格式

#### 清理模式與替換模式報告

**檔名範例**：`Cleanup_Report_20241231_143025.csv`

**欄位結構**：
```csv
檔案路徑,處理狀態,錯誤訊息
"C:\Documents\file1.docx",成功,
"C:\Documents\file2.xlsx",失敗,"檔案被鎖定"
```

#### 讀取模式報告

**檔名範例**：`Metadata_Report_20241231_143025.csv`

**欄位結構**：
```csv
檔案路徑,標題,作者,公司,...
"C:\Documents\file1.docx","年度報告","張三","ABC公司",...
"C:\Documents\file2.xlsx","財務統計","李四","XYZ公司",...
```
*欄位會根據您選擇的中繼資料項目動態生成*

## 常見問題

### Q: 為什麼某些檔案處理失敗？
**A**: 可能的原因包括：
- 檔案正被其他程式開啟（被鎖定）
- 檔案損毀或格式不正確
- 檔案權限不足
- Office 版本不相容

### Q: 處理會修改檔案內容嗎？
**A**: 不會。工具只清除中繼資料（檔案屬性），不會修改文件的實際內容。

### Q: 為什麼需要安裝 Microsoft Office？
**A**: 工具使用 Office 的 COM 物件來安全地操作 Office 檔案，因此需要安裝 Office。PDF 檔案處理不需要 Office。

### Q: PDF 檔案處理有什麼限制？
**A**: PDF 處理使用不同的技術。若要完整清理 PDF 中繼資料，建議將 itextsharp.dll 放在與工具相同的目錄。讀取模式可使用系統內建功能。

### Q: 可以還原清除的中繼資料嗎？
**A**: 不可以。中繼資料一旦清除就無法還原，請在執行前確認或備份重要檔案。建議先使用「讀取模式」查看中繼資料內容。

### Q: 工具會留下使用痕跡嗎？
**A**: 不會。工具會還原檔案的原始時間戳記（建立時間和修改時間）。

## 注意事項

⚠️ **重要提醒**：
- 執行前建議備份重要檔案
- 確保有足夠的檔案存取權限
- 關閉所有目標檔案（不要在 Office 中開啟）
- 大量檔案處理可能需要較長時間
