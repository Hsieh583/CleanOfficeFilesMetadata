# Office 檔案中繼資料清理工具

一個基於 PowerShell + .NET Windows Forms 的免安裝工具，用於批次清除 Office 檔案（Word、Excel、PowerPoint）的個人資訊與中繼資料，並還原檔案的原始時間戳記。

## 功能特點

- 🎯 **批次處理**：一次處理多個檔案和資料夾
- 📝 **支援多種格式**：Word (.doc, .docx)、Excel (.xls, .xlsx)、PowerPoint (.ppt, .pptx)
- 🔒 **隱私保護**：清除作者、公司、經理等敏感資訊
- ⏰ **時間戳記還原**：保持檔案原始的建立和修改時間
- 📊 **詳細報告**：自動生成 CSV 格式的處理報告
- 🖥️ **圖形介面**：直觀的雙標籤設計，操作簡單
- 🚀 **免安裝**：單一 .ps1 檔案，雙擊 .bat 即可執行

## 快速開始

### 方式 1：使用批次檔 (推薦)

1. 下載 `OfficeClear.bat` 和 `OfficeClear_Tool.ps1` 到同一資料夾
2. 雙擊 `OfficeClear.bat` 啟動工具
3. 在介面中選擇目標資料夾和處理選項
4. 點擊「開始執行」按鈕

### 方式 2：直接執行 PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File ".\OfficeClear_Tool.ps1"
```

## 使用說明

### 設置標籤

#### 1. 選擇目標資料夾
- 手動輸入路徑，或
- 點擊「瀏覽...」按鈕選擇資料夾

#### 2. 選擇檔案類型
選擇要處理的檔案類型（可多選）：
- ☑ Word (.doc, .docx)
- ☑ Excel (.xls, .xlsx)
- ☑ PowerPoint (.ppt, .pptx)

#### 3. 選擇要清除的中繼資料項目
選擇要清除的項目（可多選）：
- ☑ 標題 (Title)
- ☑ 主旨 (Subject)
- ☑ 作者 (Author)
- ☑ 經理 (Manager)
- ☑ 公司 (Company)
- ☑ 類別 (Category)
- ☑ 關鍵字 (Keywords)
- ☑ 備註 (Comments)

**快速操作**：
- 「全選」按鈕：勾選所有項目
- 「取消全選」按鈕：取消所有項目

#### 4. 處理選項
- ☑ 包含子資料夾：遞迴處理所有子資料夾中的檔案

### 進度標籤

執行期間會自動切換到進度標籤，顯示：
- **進度條**：視覺化處理進度
- **狀態標籤**：當前處理的檔案名稱和進度 (n/總數)
- **執行日誌**：實時顯示處理結果
  - `[✓]` 表示成功
  - `[✗]` 表示失敗
  - `[i]` 表示一般資訊

### 控制按鈕

- **開始執行** (綠色)：開始清理流程
- **取消** (紅色)：中止正在執行的任務
- **打開報告** (藍色)：開啟生成的 CSV 報告

## 處理報告

每次執行完成後，會在程式所在目錄自動生成 CSV 報告。

### 報告格式

**檔名範例**：`Cleanup_Report_20241231_143025.csv`

**欄位結構**：
```csv
檔案路徑,處理狀態,錯誤訊息
"C:\Documents\file1.docx",成功,
"C:\Documents\file2.xlsx",失敗,"檔案被鎖定"
```

## 常見問題

### Q: 為什麼某些檔案處理失敗？
**A**: 可能的原因包括：
- 檔案正被其他程式開啟（被鎖定）
- 檔案損毀或格式不正確
- 檔案權限不足
- Office 版本不相容

### Q: 處理會修改檔案內容嗎？
**A**: 不會。工具只清除中繼資料（檔案屬性），不會修改文件的實際內容。

### Q: 為什麼需要安裝 Microsoft Office？
**A**: 工具使用 Office 的 COM 物件來安全地操作檔案，因此需要安裝 Office。

### Q: 可以還原清除的中繼資料嗎？
**A**: 不可以。中繼資料一旦清除就無法還原，請在執行前確認或備份重要檔案。

### Q: 工具會留下使用痕跡嗎？
**A**: 不會。工具會還原檔案的原始時間戳記（建立時間和修改時間）。

## 注意事項

⚠️ **重要提醒**：
- 執行前建議備份重要檔案
- 確保有足夠的檔案存取權限
- 關閉所有目標檔案（不要在 Office 中開啟）
- 大量檔案處理可能需要較長時間

- ✅ 不修改系統設定或登錄檔
- ✅ 不寫入系統目錄
- ✅ 使用 Try-Catch-Finally 確保資源釋放
- ✅ 自動清理 Office 進程和 COM 物件
